# Public flashing procedure

Публичный snapshot не содержит заводских дампов и бинарных загрузчиков. Перед
экспериментом подготовьте собственный резервный дамп и получите необходимые
инструменты из официальных источников.

Минимальные правила:

1. Использовать только изолированное питание 3,3 В.
2. Проверить чип и размер flash командой идентификации.
3. Считать собственную flash минимум дважды и сравнить размеры, SHA-256 и `cmp`.
4. Записывать только согласованный диапазон приложения; не стирать всю flash.
5. Выполнить readback того же диапазона и сравнить его с образом.
6. Только после этого запускать CPU и проводить Zigbee-тест.

Команды, содержащие конкретный локальный порт, уникальные идентификаторы или
сырые дампы, не должны попадать в issues и документацию проекта.
