# Contributing

Перед изменениями запустите host-тесты:

```sh
SANITIZE=undefined ./scripts/test_application.sh
```

Для изменений Zigbee-дескрипторов или flash-layout добавьте тест, обновите
ограничения в `docs/` и укажите, что проверено статически, в host-эмуляции и на
реальном железе.

Не добавляйте в pull request:

- полные дампы flash и сырые логи устройств;
- MAC, UID, Zigbee-ключи, PAN/short address и другие уникальные данные;
- драйверы, загрузчики и SDK-архивы без подтверждённых прав распространения;
- результаты, которые выглядят как подтверждение работы Алисы, если проверен
  только Zigbee join.
