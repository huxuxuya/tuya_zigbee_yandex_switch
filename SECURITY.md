# Security policy

Проект экспериментальный и может повредить устройство или подключённую нагрузку
при неправильном подключении. Не подключайте плату к 230 В во время прошивки и
отладки.

Не публикуйте в issues и pull requests полные дампы flash, ключи, MAC/UID,
координаты Zigbee-сети или другие уникальные данные. Для сообщения о проблеме
сначала обезличьте лог и оставьте только минимальный воспроизводимый фрагмент.

На текущем этапе официальные security updates и гарантии восстановления
устройства не предоставляются.
