# Private hardware artifacts

Полные дампы flash и сырые логи намеренно не входят в публичный репозиторий.
Они могут содержать закрытый код производителя, MAC/UID, ключи, калибровочные
данные и другие уникальные значения.

Храните такие файлы локально в `dumps/private/`. Эта директория и дампы в
`dumps/` исключены из Git. Перед любым публичным отчётом оставляйте только
обезличенные метаданные: тип чипа, размер памяти, проверяемый диапазон и
контрольные суммы образов без возможности восстановить содержимое.
