## Зачем менять прошивку

Заводской выключатель Tuya уже подключается к «Дому с Алисой»: можно включать
и выключать реле, видеть их состояние и события переключения. Но у используемого
здесь устройства этим доступные функции ограничиваются.

Прошивка нужна для расширенных возможностей: отделить нажатие клавиши от реле,
передавать разные нажатия для сценариев и настраивать индикацию.

**Идея — использовать возможности существующего выключателя вместо покупки
выключателя Яндекса ради его функций.** В проекте реализуется соответствующая
логика управления и настроек.

> **Текущая версия — для самостоятельной прошивки и проверки.**
> Сборка, тесты на компьютере и запись на устройство проверены.
> Полная работа с Алисой и силовой частью ещё требует подтверждения.
> Это не заявление о полной замене всех функций оригинального выключателя.

**Пример пользы:** клавиша может отправить событие для сценария, не отключая
питание своего светильника. Разные нажатия позволяют назначить разные действия,
если они доступны в карточке устройства и сценариях Алисы.

Заводская колонка описывает **наш экземпляр Tuya в «Доме с Алисой» по наблюдениям
владельца**, а не все модели Tuya и не возможности приложения Smart Life.

¹ **Реализовано в коде; это не отметка о полной проверке через Алису.**
Доступность настроек и событий в приложении, работа сценариев и физических реле
нуждаются в сквозной проверке на устройстве. Подробности — в
[статусе проекта](docs/public-status.md).

## Совместимость

Проект разрабатывается для **двухклавишного Tuya с модулем ZT3L**,
как на фото. Модуль — небольшая плата внутри выключателя, отвечающая за связь
и выполнение прошивки.

| Проверить перед установкой | Целевое устройство |
| :--- | :--- |
| Число клавиш | Две |
| Маркировка радиомодуля | Tuya ZT3L |
| Контроллер / память | Telink TLSR825x / flash 1 MiB |
| Плата | Распиновка должна совпадать с исследованной ревизией |
| Умный дом | Устройство Яндекса со встроенным Zigbee-хабом |

По внешнему виду или надписи «Tuya» совместимость определить нельзя.
Другой модуль, чип или разводка платы требуют отдельной адаптации прошивки.

## Установка

Понадобятся совместимый выключатель, компьютер, программатор **TB-04 с
UART2SWire** и изолированное питание 3,3 В. Это аппаратная прошивка:
устройство нужно разобрать и подключиться к плате.

1. **Проверьте совместимость.** Определите модуль, чип и ревизию платы.
2. **Сохраните заводскую прошивку.** Сделайте резервную копию своего устройства.
3. **Соберите и запишите образ.** Следуйте документации по сборке и записи.
4. **Проверьте подключение к Алисе.** После проверки записи выполните
   сопряжение и проверьте доступные настройки.

**[Сборка прошивки →](docs/build-baseline.md)** ·
**[Порядок записи и проверки →](docs/public-flashing.md)**

Публичная документация пока рассчитана на человека с опытом прошивки:
это не автоматический установщик и не пошаговый мастер для новичка.

> **Отключите 230 В перед разборкой и прошивкой.**
> Для стенда используйте только изолированное питание 3,3 В.
> Работа силовых реле под сетевым напряжением не подтверждена для эксплуатации.

## Частые вопросы

**Можно просто установить прошивку через Алису?**

Нет. Текущий способ установки — подключение программатора к плате.
Обновление по воздуху (OTA) не подтверждено.

**Подойдёт любой выключатель Tuya?**

Нет. Нужны указанные модуль, память и совместимая разводка платы.

**Это полностью заменяет выключатель Яндекса?**

Это цель проекта для поддерживаемого оборудования. Часть логики уже
реализована; полная функциональная и аппаратная совместимость пока не подтверждена.

**Нужно ли разбираться в электронике?**

Для установки — да, либо нужна помощь специалиста. Потребуются разборка,
проверка контактов и работа с программатором.
