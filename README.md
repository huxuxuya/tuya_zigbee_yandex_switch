# Tuya Zigbee → Алиса

**Альтернативная прошивка двухклавишного выключателя Tuya для Дома с Алисой.**

ZT3L · Telink TLSR825x · Zigbee · Экспериментальный проект

[Совместимость](#совместимость) · [Быстрый старт](#быстрый-старт) · [Прошивка](docs/public-flashing.md) · [Статус](docs/public-status.md)

</div>

---

Идея — подключить выключатель Tuya напрямую к Zigbee-хабу Яндекса и управлять
каналами, режимами клавиш и индикацией через «Дом с Алисой», приблизив поведение
к выключателю Яндекса. Для этого проект заменяет заводскую прошивку и
реализует нужные Zigbee-команды и настройки.

> **В разработке.** Сборка, тесты и запись на стенде проверены. Полная
> совместимость с Алисой и работа силовой части пока не подтверждены.

## Совместимость

| Параметр | Целевая конфигурация |
| :--- | :--- |
| Выключатель | Двухклавишный Tuya, исследованная плата на фото |
| Радиомодуль / контроллер | ZT3L / Telink TLSR825x |
| Flash | 1 MiB |
| Подключение к умному дому | Zigbee-хаб Яндекса; совместимость в разработке |
| Запись прошивки | TB-04 с UART2SWire, интерфейс SWire |

Одинаковый корпус или надпись Tuya не гарантируют совместимость. Для другой
платы нужно проверить чип, объём flash и распиновку клавиш, реле и LED.
Образы для других модулей и контроллеров здесь не заявлены.

## Быстрый старт

Клонировать проект и запустить проверки логики на компьютере:

```sh
git clone https://github.com/huxuxuya/tuya_zigbee_yandex_switch.git
cd tuya_zigbee_yandex_switch
SANITIZE=undefined ./scripts/test_application.sh
```

Для сборки прошивки нужны Docker и подготовленный SDK/toolchain.
Следуйте [инструкции по сборке](docs/build-baseline.md), затем
[инструкции по записи](docs/public-flashing.md).

> **При прошивке отключите 230 В.** Используйте изолированное питание 3,3 В,
> проверьте распиновку и сохраните резервный дамп своего устройства.
